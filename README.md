# Investment Memento

> 영화 <메멘토>처럼, 과거의 나(투자 판단의 근거와 가설)를 잊지 않도록 기록하고
> 주기적으로 리마인드하며, AI가 그 가설에 영향을 줄 새로운 정보를 계속 조사해주는
> **투자 판단 보조 노트 앱**.

## 핵심 컨셉

개인 투자자는 자신이 세웠던 가설과 전제를 시간이 지나며 잊어버리고, 그 결과 과거의
논리와 모순되는 판단을 반복한다. 이 앱은 그 기억을 구조화해 대신 들고 있는다.

1. **기록(Record)** — 판단 당시의 근거·관점을 가설과 시나리오 구조로 저장한다.
2. **리마인드(Remind)** — 주기적으로 과거 기록을 다시 보여줘 판단의 일관성을 점검하게 한다.
3. **추적(Track)** — AI가 각 가설과 관련된 새 뉴스·데이터를 지속 조사해 요약한다.
4. **재평가(Re-evaluate)** — 시나리오 확률을 갱신하고, 판정 시점이 오면 회고로 이어진다.

### 노트는 검증 가능한 구조를 가진다

노트는 자유 텍스트가 아니다. 하나의 노트는 하나의 투자 대상에 대한 **가설(Thesis)**을
가지며, 가설은 하나 이상의 **갈래**(질문 + 판단 시점)로 검증되고, 각 갈래는 배타적인
답들인 **시나리오**로 갈린다. 시나리오마다 판정 방법(`auto` 공개 수치 / `manual` 사람이
확인 / `complement` 나머지)을 정해 두므로, 시점이 오면 "예상한 일이 일어났는가"를
판정할 수 있다.

**결과는 숫자로, 논리는 회고로.** 자동 판정은 결과 축만 담당하고, "그게 내가 생각한
이유 때문이었는가"는 판정 후 회고록에서 AI 자료조사 + 사용자 서술로 검증한다.
회고록이 이 앱의 최종 산출물이다.

### 보유 종목과 매매 기록

관점 기록과 별개의 축이 아니라, 가설에 대한 **행동**의 기록이다.

- 원본은 매매 기록(날짜·매수/매도·단가·수량·코멘트)이고 보유 잔고는 전부 파생 값이다 —
  수량을 직접 입력받지 않아 기록과 잔고가 어긋날 길을 구조적으로 막는다.
- 배당은 장부의 한 줄(`dividend`)이고, 환전은 달러의 매매로 기록한다(원→달러 = 달러 매수).
  미국 주식 손익은 달러로만 계산해 종목 판단과 환율 판단을 섞지 않는다.
- 수익률은 종목 단위(이동평균 평단·평가/실현 손익)와 포트폴리오 단위(XIRR, 원화 기준
  전체 + 달러 축)로 제공한다. 통화를 섞는 합산(총자산)은 만들지 않는다.
- 현재가는 실시간 스트리밍이 아니라 화면을 열 때 온디맨드 조회(짧은 전역 캐시 통과)이며,
  조회 시점을 항상 함께 표기한다.
- 이 화면의 진짜 산출물은 **"보유 중인데 판단 기록이 없는 종목"**이다 — 그 자리에
  노트 작성 넛지를 세운다.

### AI의 역할과 경계

AI는 리서치·요약·리마인드 큐레이션·회고 초안·소크라테스식 질문을 담당한다.
단, **가설은 항상 사용자의 입에서 나와야 한다** — AI가 완성된 가설 문장을 주고
수락받는 방식은 금지다(그러면 회고에서 검증되는 것이 AI의 논리가 된다).
**시나리오 확률도 AI는 숫자를 내지 않는다** — 답별로 뒷받침 자료를 갈라 보여줄 뿐,
배분은 사용자가 한다(앵커링이 걸리면 노트에 남는 것이 내 판단이 아니게 된다).
매수/매도 의견 자체는 프롬프트 단에서 제한하지 않되, 면책 고지는 UI 레벨에서 상시
노출한다.

## 설계 원칙 (요약)

- **빈 칸 원칙**: 모르는 값은 지어내지 않고 비워 둔다. 지어낸 단가로 계산한 수익률은
  하지도 않은 판단이다.
- **기록을 강요하지 않는다**: 회고록·코멘트는 권하되 압박하지 않는다. 개수를 세어
  몰아붙이지 않는다.
- **실시간 시세가 필요 없는 비용 구조**: 종가 기준 하루 1회 평가 + 온디맨드 조회로
  무료/저비용 데이터 소스만으로 운영 가능하게 설계한다.
- **적중률만 보여주는 것은 금지**: 적중률은 운을 실력으로 포장하는 지표다. 판단 패턴
  분석("결과가 맞은 8건 중 3건은 논리가 틀렸다")이 목표다.

## 데이터 모델 뼈대

```
User
 ├─ trades: [Trade]        매매 기록 — 잔고·평단·실현손익은 여기서 파생
 ├─ exchanges: [Exchange]  환전 기록 — 달러를 자산처럼 다룬다
 └─ Note                   투자 노트 (target / thesis / 갈래 / 시나리오)
     ├─ Conversation       원본 대화 (수정·삭제 불가)
     ├─ 근거 항목           내 논리가 참이라면 먼저 일어나야 하는 일 (서술)
     └─ 회고록              판정 후 작성, [사용자] 저작 표기
PnlSnapshot                손익 추이의 파생 캐시 — 야간 배치가 적재, 언제든 재계산 가능
```

전체 모델과 아키텍처는 `docs/development-plan.md` §5–6 참고.
